# Onboarding New Application

1. Uygulama repo'suna minimal workflow dosyalarini ekle.
2. `NuGet.config` icinde Nexus proxy kullan.
3. Deployment tipi icin `deployment_type: iis` veya `deployment_type: kubernetes` belirle.
4. SonarQube project key ve GraphNode project key olustur.
5. Nexus repository, Harbor project ve Jira SDLC project mapping kayitlarini tamamla.
6. DEV/TEST/PROD GitHub environment secret'larini ayri tanimla.
7. Uygulama repo workflow'lari merkezi platformu release tag ile cagirsin.
